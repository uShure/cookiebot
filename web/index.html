      One-time setup

      Add Cookie Chain to Nightly

      Nightly only switches to networks it already knows. If it shows Solana → Unknown with a greyed-out Change button, add the network once:

      1. In Nightly, open the network picker (the Solana label at the top) or Settings → Networks.
      2. Choose Add network / Custom SVM network and paste these values:
      Name
      Cookie Chain
      RPC URL
      https://rpc.cookiescan.io
      WebSocket
      wss://rpc.cookiescan.io
      1. Save it, come back here and tap Try again. Approve the switch in Nightly.
